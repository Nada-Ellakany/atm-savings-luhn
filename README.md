# ATM, Savings & Luhn

## Overview
This repository contains Python implementations of three programming tasks that demonstrate problem-solving, algorithm design, and fundamental Python programming concepts.

## Tasks

### 1. Cash Dispenser
Simulates an ATM that dispenses cash using 500, 200, 100, and 50 EGP banknotes while validating withdrawal limits.

### 2. Savings Goal Calculator
Calculates the number of months required to reach a savings goal based on monthly deposits and compound interest.

### 3. Credit Card Validator
Implements the Luhn Algorithm to determine whether a credit card number is valid.
